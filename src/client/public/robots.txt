# Yume. Refer to paragraph 5.5.3 of docs/architecture.md.
#
# The public page is the only page with content for a search engine. The
# routes /admin, /consent, /dashboard and /login are for a person with a
# session or on the way to a session, and a crawler that opens one of them
# receives the same HTML of the application with no data.
#
# Each language other than the base language has a prefix, for example
# /en/dashboard. The lines with `/*/` block those paths. Google and Bing read
# the character `*`. Refer to paragraph 5.8 of docs/architecture.md.
#
# The pre-render writes `sitemap.xml` with each public page: the public page,
# the calculator, the pages of the catalogue, the guides and the legal pages.
# The address is absolute, as the format asks. `site.test.ts` examines it.

Disallow: /admin
Disallow: /consent
Disallow: /dashboard
Disallow: /login
Disallow: /*/admin
Disallow: /*/consent
Disallow: /*/dashboard
